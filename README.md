# АвтоЗабота

Сервис напоминаний о плановом ТО и замене расходников. Учебный проект СевГУ, 2026.

| Папка | Что внутри |
|---|---|
| [`app/`](app/README.md) | **Мобильное приложение на Flutter.** Логика, хранение данных, экраны на стандартных компонентах. Это основная версия. |
| [`avtozabota/`](avtozabota/README.md) | Python-прототип логики. На нём придумывались и проверялись правила расчёта; подробное описание правил — в его README. |
| `app/assets/data/` | Справочники: регламенты ТО 18 моделей и 76 городов. Общие для приложения и прототипа. |
| [`ДЛЯ_ДИЗАЙНЕРА.md`](ДЛЯ_ДИЗАЙНЕРА.md) | Как запустить проект, какие данные на каких экранах и как переносить дизайн в код. |
| [`CLAUDE.md`](CLAUDE.md) | Заметки для Claude Code: структура, команды, правила проекта. |

Что умеет приложение: машины пользователя; график замены масла, фильтров, колодок, тормозной жидкости и свечей по пробегу и времени (регламенты 18 моделей, учёт двигателя); сезонная смена шин по прогнозу погоды и закону; история обслуживания; уведомления за 7 и 1 день.

Логика в обеих версиях одинаковая и проверяется одинаковыми тестами с одинаковыми цифрами. Если меняете правило расчёта, меняйте его в обеих версиях и запускайте оба набора тестов:

```bash
cd app; flutter test
```

```bash
cd avtozabota; python -m unittest discover -s tests -t .
```
